# Library

This directory is the shelf.

Each numbered directory is a book, not a documentation section. A book may contain chapters, fragments, notes, case studies, diagrams, or references, but its center of gravity should remain conceptual.

Current books:

- [01-living-systems](01-living-systems/)
- [02-ontahi-for-developers](02-ontahi-for-developers/)

Future books may include a runtime specification, RFCs, and a visual or writing style guide. They
should appear when the work asks for them, not before.
